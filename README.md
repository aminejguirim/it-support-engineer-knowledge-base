# IT Support Engineer – Knowledge Base

Documentation technique et portfolio professionnel consacré au support informatique, aux systèmes, réseaux, environnements Microsoft et à la cybersécurité.

## Démarrer en local

```bash
python -m venv .venv
# Windows PowerShell
.venv\\Scripts\\Activate.ps1
# macOS / Linux
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

Ouvrir http://127.0.0.1:8000.
